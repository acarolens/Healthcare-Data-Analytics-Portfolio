# Healthcare Data Analytics Portfolio

Bem-vindo ao meu portfólio de projetos em Análise de Dados.

Este repositório reúne projetos desenvolvidos durante minha atuação na área de Analytics em Saúde, com foco na automação de processos, análise de indicadores assistenciais, manipulação de dados e desenvolvimento de soluções para apoio à tomada de decisão.

Embora os dados originais tenham sido removidos por questões de confidencialidade, todos os projetos preservam a lógica de implementação, as regras de negócio e a metodologia utilizada.

---

# Sobre mim

Sou estudante de Ciências de Dados e atuo com Análise de Dados aplicada à Saúde, desenvolvendo soluções para automatização de processos, tratamento de dados e construção de análises voltadas à gestão de indicadores.

Tenho experiência na manipulação de bases de dados, implementação de regras de negócio, criação de rotinas em Python e desenvolvimento de análises para suporte à tomada de decisão.

Meu principal interesse é utilizar dados para transformar processos complexos em informações claras, confiáveis e úteis para equipes técnicas e gestores.

# Projetos

## Clinical Indicators Performance Analysis

Automatização da análise de indicadores clínicos utilizando benchmarks, regras de negócio e classificação automática de desempenho.

**Principais competências**

- Limpeza de dados
- Benchmark Analysis
- Healthcare Analytics
- Visualização de dados
- KPIs
- Automação de análises

---

## Dashboard Formula Inference

Projeto de engenharia reversa para identificação automática das fórmulas utilizadas em indicadores de um dashboard.

**Principais competências**

- Algoritmos combinatórios
- Engenharia reversa
- Manipulação de dados
- Automação
- Business Intelligence

---

## REDCap Survey Generator

Ferramenta para geração automática de planilhas de importação para o REDCap a partir de listas de indicadores.

**Principais competências**

- Automação de processos
- Processamento de texto
- Padronização de dados
- Integração com REDCap
